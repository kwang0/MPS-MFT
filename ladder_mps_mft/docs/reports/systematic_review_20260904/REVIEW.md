# MPS–MFT project review — September 4, 2026

## Technical summary

**The project has a credible computational foundation and promising finite-ladder results, but it is still establishing reliable competing branches. A thermodynamic phase diagram would be premature.** The strongest next investment is to finish the pending comparisons, tighten a small set of representative states, and turn the response pilot into a controlled explanation of geometry-dependent competition.

The refactored ladder package is a substantial improvement over the legacy workflow: typed numerical contracts, separate raw-map recurrence and mixing, direct canonical energies with mean-field double counting, immutable states, preserved lineage, compact mirrors, and staged resource accounting are all valuable. These should be retained. This review identifies specific gaps rather than recommending a rewrite.

Three implementation gaps were reproduced using the actual source with lightweight fixtures: the implementation fingerprint excludes the CUDA extension; the branch reader can rank records with missing fingerprints or nonfinite reconstructed energies; and outer SCF acceptance does not gate inner DMRG stopping evidence. These are recommendations for the next solver revision. They are not evidence that the six newest square endpoints are invalid: those six pass the local terminal-file hashes, the existing recurrence screen, and the final sweep-change check.

A scientific interpretation in the existing notes needs correction. The finite-size even-particle charge gap is not the excitation eliminated by the interladder pair-breaking expansion. Its smallness alone does not invalidate that expansion. Nevertheless, the measured pair-breaking scale leaves the present transverse hopping outside a comfortably asymptotic regime, which motivates an explicit hopping-strength control.

## The implementation needs a few focused corrections

**Priority 1 — include all executable scientific code in the implementation identity.** `src/Provenance.jl:31` hashes `src/*.jl` and the selected Manifest, but omits `ext/LadderMPSMFTCUDAExt.jl` and the project files that activate extensions. A fixture changing only the CUDA extension leaves `implementation_sha256` unchanged. The wider tree hash changes, but branch selection checks the narrower implementation hash. Include the extension and relevant project metadata, version the fingerprint definition, and retain old hashes as historical identities. Normalize relative-path separators so the same source bytes have the same identity on Windows and Linux. Do not silently overwrite fingerprints on old states.

**Priority 1 — make eligibility checks reject incomplete or invalid inputs.** `src/Selection.jl:43` defaults absent fingerprints to empty strings; equality checks then accept mutually missing values. A second fixture also admits a nonfinite reconstructed energy. Require nonempty valid hashes, finite energies and densities, compatible artifact kind/schema, consistent status/period/orbit fields, and a current eligibility decision. `select_completed_runs` also silently skips unreadable files; return an exclusion table with reasons. No missing-fingerprint or nonfinite-energy defect was observed in the six latest states; these are reproduced reader-contract failures.

**Priority 1 — carry inner DMRG acceptance through the SCF record.** `run_dmrg_ground` returns `energy_converged`, but `run_scf` does not put it in `IterationRecord`, and `assess_convergence` cannot require it. A synthetic two-record fixed point with a final inner sweep change of `0.25 t` passes the outer gates. This is not a DMRG experiment: it demonstrates the missing link in the acceptance contract. Store the stopping reason and a final sweep-window check, and require adequate optimization of every final fixed-point/orbit member. The Hamiltonian identity holds for arbitrary trial states and is not an optimization-error bound. Add a final variance or suitable residual diagnostic where affordable, rather than treating eigenvalue/expectation agreement as sufficient. The latest six real endpoints have last-sweep changes of `5.87e-7`–`9.17e-7 t`, below their `1e-6 t` stopping tolerance.

**Priority 2 — distinguish physical parameters from access history.** `model_fingerprint` includes `mu_initial`, even though density is targeted and this value is a starting guess. A fixture confirms that changing only this guess changes the model identity. Move it to initialization provenance. Similarly, separate SCF stopping policy, variational-space controls, and access/mixing policy where useful. Keep strict matched-comparison defaults; do not remove fingerprint checks merely to enable a desired ranking. Higher-chi comparisons should be labeled convergence studies, not equal-fingerprint phase rankings.

**Priority 2 — make response acceptance describe what passed.** `src/BareStage2.jl:1355` stores residuals of the small projected matrix, while the discovery acceptance at line 1557 does not require small omitted-space response or amplitude validation. Retain the discovery gate but give it an explicit stage label. Add a full-field residual for each leading candidate, basis-expansion stability, and amplitude-validation status before using an eigenvalue as an instability result. Tiny projected eigensolver residuals are compatible with large physical leakage.

**Priority 2 — preserve the disconnected part of order diagnostics.** `connected_structure_factor` subtracts the local one-point product. In a symmetry-broken mean-field state that subtraction removes the elastic order contribution. Save the connected fluctuation structure factor, the disconnected Fourier intensity, and their sum, with consistent normalization. Pair diagnostics should likewise separate the anomalous product from connected fluctuations, and include cross-bond-class entries if rung-versus-leg pairing symmetry is being claimed. The present class-separated pair matrices do not by themselves establish the relative rung/leg sign. Apply `K_rho` and central-charge fits to an appropriate gapless bare/reference state; a gapped SCF state does not automatically support the same conformal interpretation.

Other useful maintenance is modest: remove tracked Python bytecode, add a root orientation page that labels the chain and ladder legacy paths, mark outdated historical statements as historical, and split the large Julia test file into fast numerical contracts, small integration checks, and launcher checks. Avoid broad GPU or tensor-library migration until a measured bottleneck requires it.

## The weak-coupling check needs the right denominator

The implemented quantity called `charge_gap` is `[E(N+2)+E(N-2)-2E(N)]/2`. It probes even-particle compressibility. In a doped Luther–Emery liquid, the total charge mode remains gapless even though spin excitations and odd-particle/pair-breaking processes cost finite energy. Therefore, `t_perp/charge_gap > 1` is not by itself a failure of the pair-breaking projection. This interpretation follows from the retained/removed manifold distinction in the original construction and from the doped-ladder phase characterization. [Bollmark et al., PRX 2023](https://arxiv.org/pdf/2207.03754), [Shen, Zhang, and Qin, PRB 2023](https://arxiv.org/abs/2303.16487).

The concern that remains is quantitative: with the measured backbone, `t_perp/|E_p|=0.6825` and `t_perp/Delta_s=0.6521`. A denominator written as `2 Delta_s` in a two-ladder excitation convention gives `0.3260`; the convention must be derived and stated, not interchanged. Neither a boolean less-than check nor an arbitrary threshold certifies the expansion. A recent materials study also emphasizes the ladder spin-gap/pair-breaking separation when assessing applicability. [Staelens et al., 2026 preprint, Sec. II.C](https://arxiv.org/html/2602.21695v1).

**Recommended control:** at one representative point, compare `t_perp/t=0.025, 0.05, 0.075, 0.1`, beginning with the cheapest informative subset. Check whether order, branch preference, and response evolve consistently as the expansion parameter decreases. These are proposed scientific values, not prepared or authorized jobs. At weak hopping, a finite ladder may have a nonzero onset even when the thermodynamic susceptibility diverges; use length dependence before interpreting that onset as a bulk critical coupling.

The registry and backbone also use slightly different denominators: the current exact registry row is `-0.1465377309 t` at chi=1000, versus `-0.1465102212 t` for the backbone hole binding. That is about a `0.0188%` coupling difference. It is small, but Stage 2 and SCF should use a common declared kernel when compared quantitatively. The registry has 107 rows and no duplicate complete parameter-plus-chi keys in this review; its row-level `rel_diff` is not a universal uncertainty estimate.

## The response calculation should explain the ordered states

**The highest-value methodological extension is response around a self-consistent normal reference.** The square bare image has normalized field norm `0.0306655`, dominated by normal exchange and Hartree terms. Consequently, zero field is not a fixed point of the full normal-field map. The present projected derivative there is an isolated-ladder diagnostic. It is not the stability matrix of the converged dressed normal state.

First solve the normal manifold self-consistently while retaining an explicitly zero anomalous source. Then measure symmetry-breaking response about that reference. For a density-targeted map, include the chemical-potential response; schematically the derivative is `dF/dx|n = F_x - F_mu n_x/n_mu`. Pairing probes around a number-conserving reference have helpful symmetry cancellations at leading order, but that does not remove the need to identify the ensemble. Use the same kernel and numerical policy as the nonlinear SCF comparisons.

For the present pilot, validate selected modes at the second amplitude and measure the omitted full-field response. Expand the basis using the leading omitted directions, including the normal exchange channel where needed. Prefer this adaptive completion to indiscriminately probing every possible field. A leading square pairing eigenvalue of about `4.6688` is interesting, but the quoted `t_perp,crit≈0.04628` is only a projected bare-reference estimate. High leakage, incomplete amplitude checks, finite size, and the nonstationary reference prevent a phase-boundary claim.

Finally, distinguish raw iteration stability from thermodynamic stability. A negative multiplier can produce alternating iterates; a physical two-sublattice state additionally needs a valid mapping to the actual transverse lattice and the partner-field energy. A positive multiplier above one identifies growth about the chosen reference, not the global energy winner or the absence of a first-order transition. The 2025 multichannel paper establishes a specific CDW two-period construction; extending it to other geometry/channel patterns still requires that mapping. [Bollmark, Köhler, and Kantian, PRB 2025](https://arxiv.org/pdf/2301.08116).

## Geometry-dependent competition is the strongest science direction

**A focused question worth pursuing is whether transverse geometry changes which instability wins after normal-state dressing.** This is more informative than a large collection of anomalous amplitudes. The density kernels already have a useful analytic distinction: with `g=t_perp²/|E_p|`, their leg-parity eigenvalues are `(6g,2g)` for cubic frustrated, `(+6g,-6g)` for cubic unfrustrated, and `(+2g,-2g)` for square. This follows directly from `src/Geometry.jl` and explains why changing geometry can change feedback signs as well as overall strength.

Use matched isolated-ladder parameters and seed protocols, then compare the predicted mode, converged spatial pattern, and within-geometry branch energy. Add an equal-effective-strength comparison where useful to distinguish coordination from frustration. Do not rank total energies across geometries: those are different Hamiltonians. A convincing result would show a robust change of ordered pattern or competition mechanism under these controls, not merely a factor-of-three change in coupling.

The broader opportunity is a controlled multichannel extension of the repulsive-ladder program. Existing MPS+MF work establishes coupled-ladder superconductivity and multichannel competition in related attractive-chain models. The local project is positioned to examine how magnetic, density, and pairing channels compete in the repulsive case. This is a plausible contribution, not an established novelty claim; the review's literature search is targeted rather than an exhaustive priority search.

The August 19, 2026 preprint by Köhler and Kantian is especially relevant. It studies mixed-dimensional t-J systems, finds that stronger pair binding need not increase the predicted critical temperature, and leaves competing instabilities as an open problem. It also identifies finite-size level crossings that can contaminate the excitation used to infer charge velocity. That Hamiltonian differs from this project's Hubbard ladder. My inference for the present work is to separate changes in the bare pairing susceptibility from changes in `g=t_perp²/|E_p|` as `V` varies, and to establish excitation character before pursuing a gap-to-temperature conversion. [Köhler and Kantian, 2026 preprint](https://arxiv.org/html/2608.18861v1).

## Stripes and pairing need a test that can distinguish coexistence from trapping

**The pending inherited-stripe comparison is a good experiment.** Follow surviving distinct endpoints with matched tighter controls, forward/reverse continuations, and at least one fresh start for each candidate basin. Track bulk charge/spin harmonics, pair amplitude and sign, wall positions, and same-Hamiltonian canonical energy. If a stripe relaxes into the same paired endpoint, that is useful basin information even without a new phase.

At density `15/16`, an OBC charge modulation near `q/pi=1/8` can arise from Friedel oscillations; it is not sufficient evidence for spontaneous charge order. Move the bulk window, vary length, and compare connected and disconnected structure factors. This issue is established in chain/ladder studies and remains directly relevant here. [White, Affleck, and Scalapino, PRB 2002](https://arxiv.org/abs/cond-mat/0111320).

A pair-density-wave study is a conditional next step if robust antiphase pairing survives. Use finite-center-of-mass pairing seeds and the full mixed-bond pair correlation matrix to distinguish sign-changing order from uniform pairing with a modulated envelope. A few nodes inherited from an initial stripe or suppressed by a plot floor are insufficient. PDW theory exists for extended Hubbard–Heisenberg ladders, but those Hamiltonians are not the present model. [Jaefari and Fradkin, PRB 2012](https://arxiv.org/abs/1111.6320).

Broader two-dimensional Hubbard work finds stripe–superconductivity coexistence in appropriate parameter regimes; it motivates the question but cannot identify the phase of these coupled ladders. [Xu et al., Science 2024](https://arxiv.org/abs/2303.08376).

## Convergence work should be narrow enough to finish

After the current jobs are reconciled, choose a few representative points: one strongly paired endpoint, one persistent stripe competitor if it survives, and one geometry-sensitive point. At each, first tighten SCF and density tolerances, then compare chi=200 and 400 and promote only the informative cases to 800 or beyond. Add length controls appropriate to the density and boundary conditions. At exact `n=15/16`, even target particle number requires lengths divisible by 16; this fits the existing `L=32,48,64,96,128` plan.

Add the missing interaction-range control: the default `r_range=4` truncates both anomalous and exchange fields. Measure the available omitted correlator tails, then check selected larger ranges, for example 6 and 8. Length and chi convergence alone do not validate a fixed range cutoff. Keep range changes in the model fingerprint and treat them as a model-truncation study.

For pair correlations, compare several bulk reference bonds and fit windows, extrapolate with discarded-weight evidence where justified, and test compatibility among the pair exponent, density exponent, and a clearly normalized `K_rho`. Established ladder calculations show that boundary placement and truncation can substantially change the inferred pairing exponent. [Dolfi et al., PRB 2015](https://arxiv.org/abs/1509.04709). Do not present OLS fit errors as the total numerical uncertainty.

Finite-temperature transitions, stiffness, complex pairing phases, noncollinear magnetism, and incommensurate transverse order require additional capabilities. The present real, spin-diagonal field ansatz and density targeting of each orbit member constrain those questions. Uniform-MPS methods are a reasonable later option for testing long commensurate bulk states, but a move to them is a substantial independent project and would still need unit-cell and bond-dimension controls. [Zauner-Stauber et al., PRB 2018](https://arxiv.org/abs/1701.07035).

Coverage included the legacy TeNPy chain and Julia chain/ladder paths; the modular ladder solver, convergence, mixing, functional, diagnostics, provenance, storage, backbone and response modules; representative campaign preparers and launcher guards; tests; current plans; numerical audits; compact results; and the literature cited above. Local validation comprised 52 terminal metadata reads; reuse of the existing history screen for 42 paths; six terminal compact manifest checks; six assertions in four focused Julia source-contract checks; and six existing spatial-analysis unit tests. The contract checks use in-memory file-shaped fixtures and no tensor computation. No full Julia suite, DMRG optimization, CUDA benchmark, scheduler query, transfer, or full-scratch verification was run.

The practical sequence is:

1. Wait for and locally audit the already pending results. Reconcile the live ledger before any additional compute decision.
2. Carry the three demonstrated implementation gaps into one small reviewed solver revision with focused regression tests and a versioned eligibility policy. Preserve current production artifacts.
3. Resolve the square chi=400 lineage comparison and any surviving stripe competitor. Publish numerical ties where the available error budget does not resolve energy differences.
4. Complete selected amplitude/basis checks, then measure response around a dressed reference and compare it with nonlinear branch outcomes.
5. Spend the retained compute budget on selected hopping, range, chi, and length controls. Broaden the grid only when it answers a specific unresolved science question.

The last documented active total, `42.024097222` node-hours, and later reservation illustrations are historical. They are not a current remaining allowance. The 400-additional-node-hour policy should continue to protect convergence work. Wall-clock forecasts for new runs require the user's current Perlmutter accounting; this review does not create reservations or launch controls.

The most consequential open questions are whether the pending high-chi lineages remain distinct, whether any stripe has a resolved energy advantage at matched controls, how the leading response changes on normal-state dressing and basis completion, and whether those conclusions survive weaker transverse hopping and larger range/length. Those answers would determine a credible paper-sized result.
