# Square finite-size comparison: seed-review configs

Four chi=200 configs cover pairing and stripe lineages at L=96 and 128.
They are generated by `scripts/prepare_phase1_finite_size_seeds.py` from the
hash-pinned L=64 chi=400 terminal **measured** fields. The new runs use fresh
MPS states and field-only inheritance; no MPS is resized.

See `docs/reports/finite_size_seeds_20260906/README.md` for the seed snapshot,
precise extension rule, numerical controls and validation.

The seed files live in ignored `output/seed_previews/`; regenerate them from
the specified synced source artifacts, or transfer the exact reviewed files
with their manifest. Paths in these configs are project-relative and work
through `load_settings` on Windows or Linux.

`pair_binding.reference_L=64` holds the measured denominator fixed across
lengths. `hamiltonian_identity_tol=1e-8` implements the user's relaxed identity
check for this new campaign. Other tight chi=400 comparison controls are kept,
with `maxdim=200`.

The `UNPREPARED_SIZE_COMPARE` output location is a review placeholder. Do not
submit these configs before the seed review and scratch/launcher preparation.
No scheduler job or reservation has been created by this directory.
